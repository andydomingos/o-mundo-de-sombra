# O Mundo de Sombra

Jogo de exploração estilo Minicraft: a Sombra explora uma ilha cheia de cavernas, tesouros, gemas, mapas e mistérios.

**Jogar:** https://andydomingos.github.io/o-mundo-de-sombra/

## Controles
- WASD / setas: andar · Shift: correr · Espaço ou clique: ação
- E: usar item · 1-9 / Q: escolher item · C: fabricar · J: diário · M: mapa · F: lanterna
- No celular: joystick e botões na tela

## Como rodar localmente
Abra o `index.html` em qualquer navegador. Não precisa instalar nada.
